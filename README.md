RAYMOND

Your Personal AI Phone Assistant

RAYMOND is a voice-first Android personal assistant designed to help users interact with and manage their phones using natural voice commands.

Features

- AI-powered natural conversations using OpenAI.
- Voice recognition and spoken responses.
- Open installed applications.
- Read accessible notifications.
- Assist with calls and text messages.
- Set timers and alarms.
- Control supported Android settings.
- Background assistant service with appropriate permissions.

Technology

- Kotlin
- Android SDK
- OpenAI API
- Android Speech Recognition
- Android Text-to-Speech
- GitHub Actions

Package

"com.raymond.assistant"

Project Status

🚧 Under development.

Security

RAYMOND uses Android permissions and approved system interfaces. Sensitive actions require appropriate user authorization.
